## Core Concepts

1. **Passive Capture**: Tally pulls window, web, and AFK events from [ActivityWatch](https://activitywatch.net/), ensuring that time tracking requires zero manual timers.
2. **Deterministic Rules & LLM Fallback**: Events are classified using prioritized rules (`app`, `title`, `url`, `repo`) with an optional Claude LLM fallback for ambiguous periods.
3. **Full Agent Parity**: The [MCP Server](mcp/server.md) exposes every time-tracking capability over stdio so AI coding agents have full read/write parity with human users.
4. **Local-First Privacy**: All data resides locally in `~/.tally/tally.db` via SQLite WAL.

## Backlog & Deferred Items

- **Cloud Sync**: Optional multi-device synchronization (deferred; current scope is strictly local-first).
- **Additional Capture Providers**: Support for alternative activity trackers beyond ActivityWatch (deferred; ActivityWatch is the primary supported provider in v1).
